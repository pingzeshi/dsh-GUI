# 启动页“深海测绘”视觉重制与验证

日期：2026-08-20

## 目标与范围

本次只重制 Electron 壳在 dsh Web 服务就绪前显示的
`renderer/splash.html`，不修改 DeepSeek Harness 官方 Web 界面、会话数据、
插件配置或 `DSH_HOME`。设计目标是把原有深色极光/液态玻璃方案收敛为更轻、
更清晰的“深海测绘图谱”，同时让进度文案来自真实启动阶段。

目标流程：

> renderer/splash.html loads -> startup phase changes environment → runtime → interface -> whale/contours/status render without errors and remain responsive.

## 视觉方案

- 底色：矿物白 `#F4F5F2`，高亮纸白 `#FAFAF8`。
- 主色：DeepSeek 钴蓝 `#4D6BFE`，辅色冰蓝 `#B9C7FF`。
- 主视觉：保留官方鲸鱼的 1,982 个目标点，改为确定性配色和聚合轨迹；
  增加扫描线、微弱漂移和鼠标斥力反馈。
- 空间语言：全屏等高线、洋流虚线和测绘十字标记；不使用卡片、玻璃容器、
  大面积光晕或装饰性数字。
- 字体：英文品牌优先 Bahnschrift，中文优先 Microsoft YaHei UI，阶段标签
  使用 Cascadia Mono/Consolas。
- 进度：固定为“环境 / 运行时 / 界面”三阶段，以方形测绘节点和细轨道表示，
  当前阶段使用钴蓝。
- 无障碍：阶段使用有序列表和 `aria-current="step"`；状态使用
  `role="status"`、`aria-live="polite"`；`prefers-reduced-motion` 下停用循环动效并
  直接绘制最终鲸鱼。

## 真实状态桥接

页面暴露只读冻结对象 `window.dshSplash`，提供 `setPhase` 和 `getState`。
主进程只在本地启动页加载时，通过 JSON 序列化参数更新阶段，不向 dsh Web 页面
注入状态。

| 启动事件 | 阶段 | 用户可见文案 |
|---|---|---|
| 开始选择运行环境 | 环境 | 正在检测运行环境… |
| 准备 WSL 内嵌运行时 | 运行时 | 正在准备 WSL 内嵌运行时… |
| 准备 Windows 本机运行时 | 运行时 | 正在准备 Windows 本机运行时… |
| Windows 归档校验/部署/版本验证 | 运行时 | 对应的真实校验、部署或验证文案 |
| 启动 dsh Web 服务 | 界面 | 正在启动本地界面… |
| 获取本地 URL | 界面 | 正在连接本地界面… |

状态会在 `did-finish-load` 后重放，因此即使运行时准备快于启动页脚本加载，也不会
丢失最新阶段。Canvas 不可用时，文字状态接口仍可工作。
