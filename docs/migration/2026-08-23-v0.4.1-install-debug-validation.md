## 本轮发现并修复的问题

启动页重制提交位于桌面版 `0.4.0` 发布提交之后，但 `package.json`、根
`package-lock.json` 和 `runtime/package.json` 仍标记为 `0.4.0`。因此新旧安装包
虽然内容不同，控制面板、文件属性和安装包文件名却无法区分，不利于确认覆盖更新
是否真正生效，也会给后续更新与排障带来歧义。

本轮把三个版本入口统一修订为 `0.4.1`。内嵌 dsh 运行时仍使用项目已锁定并完成
可复现、安全部署和双模式验收的 `@deepseek-ai/dsh@0.1.0-rc.7`；没有把桌面端
修订号调整与 dsh 依赖升级混为一次变更。
